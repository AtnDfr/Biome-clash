# Tasks

<Un bloc par jalon, dans l'ordre : Proto, MVP, v1. Un jalon est fini et jouable avant le suivant.
Chaque tâche couvre un seul comportement et cite ses ids d'exigences. Chaque sous-tâche est un cas
testable : en jouant, ou par un test automatique (noté « test »).>

## Jalon : Proto
**Ce que ce jalon doit prouver :** <par exemple « choisir le bon couloir selon son biome est
amusant »>

- [ ] 1. <titre de la tâche> (<ids>)
  - [ ] 1.1 <cas normal> (<id>)
  - [ ] 1.2 <cas limite> (<id>)
  - [ ] 1.3 test : <ce que vérifie le test automatique> (<id>)
- [ ] 2. <titre> (<ids>)
  - [ ] 2.1 ...
- [ ] 3. Vérification du jalon : je joue sur le vrai support et je suis le plan de test manuel

**Bilan du jalon :** <à remplir à la fin : ce qui est amusant, ce qui ne l'est pas, ce qu'on change>
